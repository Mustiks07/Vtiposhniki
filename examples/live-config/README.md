# Проверенная конфигурация настоящего оценщика

Эта пара profile/corpus проверена 2026-11-07 одним fresh production-запуском через
реальный API/worker. Модель: `gemini-3.5-flash-lite`, prompt `cqa-eval-v2`, 8 критериев
исходной рубрики, один вызов, artifact complete. Это smoke, не измерение AI accuracy.

JSON содержит только настройки и имя `GEMINI_API_KEY`, не сам ключ. Пустой корпус
означает отсутствие базы знаний: оценщик обязан честно обозначать это ограничение.
Корпус/профиль проходят канонические модели; content_hash рассчитан только domain.

Для новой установки скопировать каталоги `profiles` и `corpora` в локальный
`data/private/config` (или свой CQA_CONFIG_DIR), задать ключ в приватном `.env` и
запустить API по README. Не перезаписывать ранее зарегистрированный profile ID/version
другим содержимым. Меняя настройки, создавайте новую версию профиля.

Для текущего рабочего места интегратора конфигурация уже подготовлена в
`data/private/live/config`, `.env` указывает соответствующую БД. Выбирать профиль
`live-gemini-35-flash-lite-v1`. Предыдущие неудачные попытки сохраняются как история.

Профиль ограничивает количество вызовов, tokens и deadline, не включает reviewer
или fallback. Тариф в приложение не внедрён: cost остаётся unknown. Доступность
бесплатной квоты зависит от аккаунта; актуальная модель заменяет недоступную новым
пользователям 2.5 Flash-Lite по ответу самого провайдера.
[Официальные тарифы Gemini](https://ai.google.dev/gemini-api/docs/pricing).

Ни вход живого прогона, ни ответы, runtime-БД и секреты здесь не публикуются.
