# Xerosharc: подключение и версии оценщика

Default приложения — **`live-xerosharc-quality-v1`**, версия `1`,
prompt `cqa-eval-v4`. Он сначала проверяет применимость, затем условия критерия,
доказательства и согласованность ответа с объяснением. Отдельно уточнено различие
между общей консультацией и раскрытием состояния конкретного счёта.
Критерии, веса и арифметика исходной рубрики не менялись.
Для контрольных десяти чатов отдельно выбран v7:
[профили контроля](../control-config/README.md), [основание выбора](../../docs/CONTROL_CHAT_PROFILE.md).

`live-xerosharc-sol-v1` сохраняет исходный `cqa-eval-v2`; промежуточный
`live-xerosharc-rubric-v3` оставлен для воспроизводимости пилота. Новые инструкции
не переписывают прежние профили и сохранённые оценки. Полный результат измерения
и ограничения — в [отчёте качества](../../docs/QUALITY_WORKFLOW.md).

## Исходная проверка подключения

7 ноября 2026 проверен полный fresh-запуск на одном **выдуманном** разговоре через
настоящие API/worker: 8 критериев и 8 доказательств, artifact complete, domain
validation и profile hash совпали. Результат и job сохранились после restart.
Это проверка подключения и обработки, не измерение точности модели.

Запрошено `gpt-6.1-sol`; шлюз сообщил модель **`xeros_core`**. CallRecord хранит
оба значения раздельно. По этому ответу нельзя подтвердить, какая модель работает
за шлюзом. Официальный экспорт использует только reported actual model.
Прямые OpenAI/Anthropic API этим подключением не заявляются.

Один provider call: 5081 input + 1503 output tokens; из output 161 reasoning.
Цена неизвестна: таблица тарифов не настроена. Каталог и smoke не доказывают
заявленный продавцом остаток токенов или стабильность будущих запросов.

Копировать `profiles/` и `corpora/` в свой `CQA_CONFIG_DIR` (по умолчанию
`data/private/config`) и заполнить **только локальный** `.env`:

```dotenv
XEROSHARC_API_KEY=<ваш ключ>
XEROSHARC_BASE_URL=https://xerosharc.site/v1
CQA_DEFAULT_EVALUATOR_PROFILE=live-xerosharc-quality-v1
```

После перезапуска API форма предварительно выбирает `live-xerosharc-quality-v1`.
Профиль содержит только имя переменной ключа, ограничивает calls/tokens/deadline,
не использует fallback/reviewer или test evaluator. Пустой корпус явно отражается
в limitations. Отсутствующий ключ/невалидный endpoint блокируют production.
Менять зарегистрированный ID/version нельзя: для других настроек создать новую
версию. Сохранённая DEV сдача Gemini не заменяется автоматически: результат
Xerosharc хранится отдельным кандидатом до проверки полноты и качества.

## Расход и ограничения

Профиль допускает до 4 вызовов на задание, 1 транспортный повтор, 1 исправление
формата, 2 попытки задания, 360 секунд на задание и 120 секунд на вызов.
Reviewer и fallback отключены; действует настоящий production evaluator.
Неполная оценка остаётся неполной и доступна в очереди «Нужна проверка».

Каталог моделей шлюза не сообщает тариф. Цена купленного у посредника пакета
не подтверждает правила списания токенов конкретной модели. В карточке показан
расход input/output из API; reasoning уже включён в output. Цена остаётся
неизвестной до подтверждения тарифа, без подстановки цены другого провайдера.
