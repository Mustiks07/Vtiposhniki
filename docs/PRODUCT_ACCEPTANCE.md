## Что работает

- Вставка обычного текста с предпросмотром, проверкой ролей/времени и запуском оценки.
  Дополнительно закрыта ошибочная допустимость ISO-смещений вроде `+99:99`.
- Сравнение показывает изменения правил, применимости, ответов, флагов и серверных
  вкладов. Ссылка открывает доказательства нужной стороны. Длинный вклад показан
  с `≈`, точное значение доступно в подсказке, расчёт остаётся на сервере.
- Сводка запуска показывает фактически сообщённую модель, все вызовы, токены,
  длительность и серверную стоимость. Если результат переиспользован после платной
  неудачной попытки, интерфейс больше не обещает «новых вызовов не было».
- Пять реальных DEV-записей воспроизводятся в production-сборке. Для каждой проверены
  play, ручная перемотка контролами плеера и продолжение движения времени без ошибки
  декодирования. Это проверка браузерного воспроизведения, не прослушивание/оценка речи.

Аудиопрокси читает не более 64 KiB HTML, извлекает единственный `audio/source`,
декодирует entities, не исполняет скрипты. Страница, media и каждый redirect проходят
проверки HTTPS, точного списка хостов и публичного IP. Поддержаны Range/206/416,
проверка Content-Range, ограниченное обновление истёкшей вложенной ссылки.
Подписанные URL не выходят в публичный API или Git. Для существующих пяти звонков
приватные ссылки добавлены штатным импортёром без изменения текста и revision.

## Разделы без изменения ответов

`original_checklist()` и опубликованный снимок v1 сохранены. Новая конфигурация
`cqa-original-v2-sections` имеет тот же semantic hash и отдельный scoring hash:

| Раздел PDF | Критерии |
|---|---|
| Начало и понимание запроса | 01–02 |
| Безопасность и решение | 03–04 |
| Ведение и завершение диалога | 05–07 |
| Грубые нарушения | 08, отдельный флаг без процента |

Domain теперь допускает группировку флага в существующую секцию, продолжая исключать
его из всех числителей и знаменателей. UI не выводит для него искусственные 0/0 или %.
На старой БД нетронутый стартовый чек-лист получает новую версию один раз; изменённые
пользовательские правила и закреплённый официальный чек-лист не переписываются.
Новая конфигурация `cqa-submit init` использует разделы. Экспорт принимает ровно две
канонические scoring-конфигурации при неизменном смысле, а не любое совпадение названия.

Пересчитаны в памяти все 65 оценок v4 и все 65 v7, включая неполные: совпали ответы,
automatic/effective итоги, флаги и каждый объект официального экспорта. Вызовов AI — 0.
На реальном `p1-ru-009` дополнительно создана сохранённая оценка с разделами:

## Оставшиеся ограничения

AI v7 не принят по умолчанию: полный DEV обнаружил регрессии и ложный critical
в двух звонках. v4 и прежний официальный DEV сохранены; это не заявление, что v4
безошибочен. Подробная таблица исправлений/ухудшений/неоднозначностей — в AI-отчёте.
Последующий раздельный анализ выбрал **v7 для контрольных десяти чатов** при
сохранении этих ограничений для звонков. [Решение и доказательства](CONTROL_CHAT_PROFILE.md).
Голосование не включено. Тариф и запас квоты не подтверждены; неизвестная цена
остаётся `null`. Условия пакета и допущения приведены рядом с метриками.

Синхронизация записи и текста остаётся **unverified**: слышимые опорные реплики до/после
пауз независимо не сверены, временная формула не выдаётся за доказательство.
Независимого проверяющего нет по сообщению владельца; человеческая приёмка и полное
пятиминутное выступление независимого участника не заявляются выполненными.
Отсутствующие временные метки при текстовом импорте сохраняются пустыми; старый
импортёр пока выводит для них технические предупреждения об отсутствии разбора времени.
