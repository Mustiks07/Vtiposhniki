## Итог

- Общая тема Graphite / Platinum / Cobalt на всех маршрутах: диалоги, импорт,
  разговор и аудио, оценка, сравнение, запуск, библиотека, версия и редактор
  чек-листа, апелляции, учебный пример, страница отсутствующего маршрута.
- Вместо ID — выдержка из запроса клиента, названия правил и профилей, дата и
  номер версии. Исходные ID остаются в технических сведениях, API и ссылках.
  Номера версий следуют порядку создания на сервере, а не строке ID или времени.
- ScoreExplanation использует contributions выбранного automatic/effective,
  не пересчитывает баллы. Доказательства открывают исходные реплики; существующая
  апелляция открывается в очереди, новая — через штатную форму.
- Учебный пример `#/example/closing-na` явно помечен учебным. Данные и генератор
  Claude сохранены; числовые значения вычисляются domain. Страница не вызывает
  AI, не создаёт оценок/апелляций/диалогов и не показывает расходы.
- Черновик текстовой вставки (текст, язык, канал, ID и результат импорта) хранится
  в памяти над маршрутизатором страниц. Переход к примеру и обратно его сохраняет.
  Подстановка примера возможна только по явному запросу и в пустое поле. Перезагрузка
  вкладки очищает черновик: содержимое разговоров не записывается в browser storage.
