# AI-ассистент проверяющего — 8 ноября 2026

Подсказки не заменяют оценку и решение человека. Каждый запрос хранится отдельно,
с закреплённым профилем, фактической моделью, вызовами и расходом. Неизвестная
цена остаётся неизвестной. Текст разговора и комментарии — недоверенные данные.

## Второе мнение в апелляции

Кнопка доступна для открытой апелляции. Оценивается только её критерий, профилем
исходной оценки и по закреплённой версии правил. Исходный ответ AI не передаётся;
комментарий рассматривается как утверждение, которое надо проверить по разговору.
Ответ не подставляется в решение. Доказательства открывают реплики транскрипта.

Один запрос — максимум один вызов, без автоматического повтора и fallback.
Повтор с тем же Idempotency-Key возвращает сохранённый результат. При перезапуске
незавершённый вызов помечается как неизвестный, а не отправляется повторно.
История хранится в отдельной таблице; API 1.5.0 добавляет POST/GET
`/api/v1/appeals/{id}/second-opinions`.

Проверено:

- 6 адресных Python-тестов: изоляция оценки/экспорта, идемпотентность, квота,
  восстановление, один критерий и недоверенный комментарий, неверные доказательства,
  запрет вызова без записи в журнал. 19 проверок контрактов также прошли.
- Новый E2E и существующий E16 апелляции — 2/2. Снимки 1366×768 и 390×844
  просмотрены, переполнения нет. Это детерминированная тестовая заглушка,
  подписанная в UI; она не доказывает смысловую точность.
- Typecheck/production build, mypy, Ruff, воспроизводимость контрактов прошли.
- Один живой вызов Gemini/v7 на выдуманном диалоге: 2,04 с от запроса до чтения
  результата, 3 150 входных + 261 выходной токен, модель по API
  `gemini-3.5-flash-lite`, стоимость неизвестна. Подсказка объяснила отсутствие

## Создать критерий с помощью ИИ

В редакторе раскрывается отдельная панель: название, описание одной фразой,
профиль модели. AI предлагает тип, варианты с якорями и долями, условие N/A
и объяснение. Ответ проходит структурную и обычную доменную валидацию.
Вес отсутствует в AI-ответе. «Добавить в черновик» создаёт новые ID и сохраняет
остальные поля черновика. Для оцениваемого критерия вес пустой до ручного ввода;
для флага он всегда 0 по доменному правилу. Любая предложенная шкала требует
подтверждения точного отображения ответов в доли; изменение шкалы отменяет
подтверждение. Сохранение — штатная новая неизменяемая версия по кнопке человека.

Профиль задаёт провайдера, модель и параметры вызова; генератор использует
отдельную инструкцию `criterion_design.SYSTEM`, не изменяет промпты оценщика.
API 1.6.0: POST/GET `/api/v1/criterion-suggestions`. История, расход, отказ
по ключу/квоте и неопределённый вызов после перезапуска сохраняются отдельно.

Проверено: 5 новых Python-тестов, 3 проверки совместимости второго мнения,
19 контрактных, 2 web-unit, один новый E2E на настоящем тестовом API;
typecheck/production build, mypy, Ruff, воспроизводимость контрактов.
Первый вызов Vitest не нашёл файл с расширением `.test.ts`: тест переименован
в используемый проектом `.test.tsx`, после чего оба теста прошли.
Снимки 1366×768 и 390×844 просмотрены; живой ответ открыт в production UI,
в том числе на узкой ширине, без переполнения. Новая версия в E2E сохраняется
только после веса и подтверждения; прежний критерий и старая версия совпадают.

Один живой Gemini/v7: 2,02 с, 429 входных + 263 выходных токена,
`gemini-3.5-flash-lite` по API, стоимость неизвестна. Чек-листы не изменились.
**Ограничение, подтверждённое этим примером:** AI предложил пересекающиеся
условия положительного ответа и N/A. Структурная валидация не доказывает
качество формулировки; человек должен устранить пересечение перед сохранением.
Этот ответ оставлен в журнале, в рабочие правила автоматически не переносился.

Архив: `data/private/defense-20261108/criterion-design/receipt.private.json`;
снимки тестового сценария — `data/private/c-e2e-tmp/criterion-designer/`,
живого UI — `data/private/defense-20261108/criterion-design/`.
Журнал: `data/private/criterion-designer-e2e-20261108.log`.

## Спросить AI про разговор

Панель в карточке отвечает только по закреплённому транскрипту, правилам и
сохранённым ответам/доменным баллам выбранного scope. Вопрос содержит revision;
устаревшая карточка отклоняется до вызова. История явно подписана scope и
версией оценки, поэтому ответ о прежнем состоянии не выдаётся за текущий.
Новые оценки, ответы и решения не создаются. Другие источники и поиск не используются.

Содержательный ответ обязан сослаться хотя бы на одну существующую реплику;
выдуманные ID, пустые доказательства и ссылка у отказа отклоняются. Это проверка
структуры доказательств, **не гарантия верности всех утверждений AI**.
Вопрос не по теме получает отказ, недостаток контекста — явное ограничение.
Вызов учитывается и при отказе. Текст вопроса, разговора и прежней оценки
передаётся как недоверенные данные. API 1.7.0: POST/GET
`/api/v1/evaluations/{id}/questions`.

Проверено: 7 новых Python-тестов; вместе с 5 тестами соседних подсказок и
19 контрактными — 31/31. Новый E2E — 1/1: ответ → реплика → отказ по погоде
→ журнал расхода → обновление страницы; сохранённая оценка полностью совпала.
Снимки 1366×768 и 390×844 просмотрены, переполнения нет. Typecheck/build,
mypy, Ruff и генерация контрактов прошли. Полные локальные наборы не повторялись.

Два живых Gemini-вызова на выдуманном диалоге:

| Вопрос | Результат | Время запроса | Токены вход / выход |
|---|---|---:|---:|
| Почему не выполнено завершение? | Объяснение сохранённого «Нет», ссылка на реплику 4 | 1,53 с | 2 965 / 68 |
| Прогноз погоды в Алматы | Отказ как вопрос вне темы, без доказательств | 1,37 с | 2 946 / 38 |

Модель по API `gemini-3.5-flash-lite`, цена неизвестна. Оценка до/после полностью
совпала. Это 2 функциональных примера, не измерение точности или полной
устойчивости к prompt injection. Профили контрольного запуска не менялись.
Архив: `data/private/defense-20261108/conversation-assistant/receipt.private.json`;
снимки `data/private/c-e2e-tmp/conversation-assistant/`,
журнал `data/private/conversation-assistant-e2e-20261108.log`.
