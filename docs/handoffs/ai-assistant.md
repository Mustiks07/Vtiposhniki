# AI-ассистент проверяющего — 8 ноября 2026

Подсказки не заменяют оценку и решение человека. Каждый запрос хранится отдельно,
с закреплённым профилем, фактической моделью, вызовами и расходом. Неизвестная
цена остаётся неизвестной. Текст разговора и комментарии — недоверенные данные.

## Второе мнение в апелляции

Кнопка доступна для открытой апелляции. Оценивается только её критерий, профилем
исходной оценки и по закреплённой версии правил. Исходный ответ AI не передаётся;
комментарий рассматривается как утверждение, которое надо проверить по разговору.
Ответ не подставляется в решение. Доказательства открывают реплики транскрипта.

Один запрос — максимум один вызов, без автоматического повтора и fallback.
Повтор с тем же Idempotency-Key возвращает сохранённый результат. При перезапуске
незавершённый вызов помечается как неизвестный, а не отправляется повторно.
История хранится в отдельной таблице; API 1.5.0 добавляет POST/GET
`/api/v1/appeals/{id}/second-opinions`.

Проверено:

- 6 адресных Python-тестов: изоляция оценки/экспорта, идемпотентность, квота,
  восстановление, один критерий и недоверенный комментарий, неверные доказательства,
  запрет вызова без записи в журнал. 19 проверок контрактов также прошли.
- Новый E2E и существующий E16 апелляции — 2/2. Снимки 1366×768 и 390×844
  просмотрены, переполнения нет. Это детерминированная тестовая заглушка,
  подписанная в UI; она не доказывает смысловую точность.
- Typecheck/production build, mypy, Ruff, воспроизводимость контрактов прошли.
- Один живой вызов Gemini/v7 на выдуманном диалоге: 2,04 с от запроса до чтения
  результата, 3 150 входных + 261 выходной токен, модель по API
  `gemini-3.5-flash-lite`, стоимость неизвестна. Подсказка объяснила отсутствие
  итогов/дальнейшей помощи и прощания. Исходная оценка полностью совпала до/после.
