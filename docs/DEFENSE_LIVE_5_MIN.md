# Защита CQA: два вводных слайда и живое приложение

Команда **Vtiposhniki**. План обязательного показа — 4:40, ещё 20 секунд
оставлены на переключения. Это план, не измеренная репетиция. Время вопросов
определяет жюри. Основной материал — работа приложения.

| Время | Экран | Действие и смысл |
|---|---|---|
| 0:00–0:20 | Слайд 1 | CQA связывает оценку с правилом и конкретной репликой. |
| 0:20–0:50 | Слайд 2, схема | Диалог, версия правил, ответ AI, расчёт, доказательство, решение человека. |
| 0:50–1:15 | Живое приложение | Список диалогов и заранее подготовленный выдуманный разговор. |
| 1:15–2:15 | Карточка оценки | Причина снижения → доказательство. Показать N/A и отдельный флаг нарушения. |
| 2:15–3:10 | Апелляция | Комментарий, решение человека, исходная и пересмотренная оценки. |
| 3:10–4:20 | Редактор и сравнение | Изменение критерия создаёт новую версию. Показать сохранённые результаты до и после. |
| 4:20–4:40 | Слайд 3 | Каждое решение можно проверить. 10/10 означает полноту обработки, не точность AI. |

Слайды 4–8 — только для вопросов или при недоступности приложения. Слайд с
73,17% и 80,49% относится к прежнему направленному аудиту Xerosharc v4/v7,
не к точности контрольной сдачи. Все семейства DEV использовались в разработке.

## Подготовка ноутбука

Рабочий адрес — `http://127.0.0.1:8001`. Для нового демонстрационного запуска
локально установлен `CQA_DEFAULT_EVALUATOR_PROFILE=boundary-gemini-v7-1`.
Одна свежая проверка: 8/8 критериев, 6,99 секунды, API сообщил
`gemini-3.5-flash-lite`. Это проверка доступности, не гарантия времени сети.

Заранее открыть сохранённую настоящую AI-оценку учебного разговора,
её доказательство, рассмотренную апелляцию, редактор и сравнение двух версий.
В обязательной части не ждать нового внешнего запроса. Сохранённый результат
называть сохранённым, учебные данные — учебными. Встроенный ручной пример
`/example/closing-na` не выдавать за результат AI.

## Вопросы жюри

- Второе мнение и «Как надо было сказать» — подсказки, они не меняют оценку.
- AI помогает подготовить критерий, но проверяет и сохраняет версию человек.
- Вопросы по разговору получают ответ со ссылками на реплики.
- Журнал хранит фактическое имя из API, вызовы и токены. Неизвестная цена не равна нулю.
- Официального GT и чистой независимой выборки нет. Диагностику разработки не называем точностью на контроле.
- Актуальный контрольный профиль и происхождение опубликованного файла указаны
  в [отчёте сдачи](PROD_SUBMISSION_20261108.md). Он отделён от локального default
  демонстрации и исторического DEV.

Прежние презентации сохранены. Колода для этого маршрута находится в локальном
пакете `output/presentation/cqa-pitch-20261108/live-demo` родительского workspace.
