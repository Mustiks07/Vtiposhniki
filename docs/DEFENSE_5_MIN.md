# Защита CQA: обязательный показ до пяти минут

Основной показ рассчитан на **4 минуты 40 секунд**, ещё 20 секунд — запас.
Время вопросов определяет жюри; гарантированного дополнительного окна нет.
Это рабочий сценарий текущего интерфейса. Учебный пример и выдуманные диалоги
явно называем учебными; сохранённые AI-оценки — сохранёнными.

## Ответы на вопросы

- **Какая точность?** Официального GT нет. Направленный аудит агента на данных
  разработки дал 90/123 → 99/123 совпадений значения и применимости в чатах
  (v4 → v7). Все семейства уже использовались в разработке; независимой выборки
  нет. Это диагностика, не оценка качества на новых чатах.
- **Почему разные профили?** В том же диагностическом аудите звонки ухудшились
  с 17/18 до 12/18, поэтому v7 выбран для контроля из чатов, а v4 сохранён для
  звонков. Опубликованный DEV исторически получен на Gemini/v2.
- **Почему N/A?** Только по условию конкретного критерия. Неустановленный факт
  хранится как undetermined; частичный официальный результат становится error.
- **Почему можно проверить ответ?** Доказательства ведут к исходным репликам,
  отсутствие действия обосновывается проверенным диапазоном, а не выдуманной цитатой.
- **Стоимость и модель?** Журнал хранит все попытки, токены, запрошенное и
  сообщённое API имя. Тариф шлюза не подтверждён; неизвестная цена не равна нулю.
- **Что со звонками?** Оцениваем расшифровку с ограничениями ASR, звук доступен
  проверяющему. Акустический анализ, темп и дикцию по тексту не заявляем.
- **Новый чек-лист?** Профиль получает семантику новой версии; арифметика остаётся
  в общем доменном модуле. Смена критерия проверяется отдельным живым сценарием.
- **Если провайдер недоступен?** Ручное продолжение через Gemini только для
  технически неуспешной части, с двумя receipt и проверкой происхождения.
  Уже успешные и partial ответы не подменяются резервом ради удобного результата.

## Расширенный запасной маршрут

Только если жюри выделит время: фильтр нарушений с automatic/effective,
версии разговора, подробный журнал расходов, новый живой запуск, официальный
валидатор и ручное переключение резерва. Этот блок не входит в обязательные
пять минут и не предполагает заранее выделенных 8–10 минут.

Если жюри спросит об AI-ассистенте, показать сохранённое «Второе мнение»
апелляции или вопрос «Почему не выполнено завершение?» в карточке второй
оценки. Это настоящие сохранённые Gemini-подсказки на выдуманном диалоге.
Ссылка на реплику работает, исходная оценка не меняется. Генератор критерия
показывать как черновик для проверки: модель может предложить пересекающиеся
условия ответа и N/A. Эти действия заменяют часть расширенного маршрута,
а не удлиняют обязательный показ.

Фактические ссылки на подготовленные локальные записи и журнал прохождения
будут закреплены в приватном пакете демонстрации; его нельзя переносить в
публичный Git вместе с рабочей БД.
